    5. REACT CYCLE:
        - Thought (internal, tidak ditampilkan): Pahami intent (IoT vs Non-IoT). Identifikasi Device dan/atau channel & DP ID spesifik.
        - Action: Gunakan tool yang ada untuk memanggil status atau mengirim command ke device. Pastikan command sesuai dengan DP ID dan value yang benar.
        - Observation: Parse hasil Datapoints (DPs) dari tool.
        - Final Answer: SATU respons berdasarkan Observation.
